# Gerador de EANs Genéricos

Uma aplicação web para gerar EANs genéricos para fins de organização interna.

## Características

- Geração de EANs a partir de códigos internos
- Interface moderna com tema escuro
- Design responsivo
- Exportação para Excel (XLSX)
- Fácil de usar

## Aviso Importante

Os EANs gerados por esta aplicação são genéricos e destinados apenas para fins de organização interna. Eles não são válidos para uso comercial e não devem ser utilizados em produtos para venda.

## Tecnologias Utilizadas

- Next.js
- TypeScript
- Tailwind CSS
- React
- XLSX

## Como Executar Localmente

1. Clone o repositório
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
4. Acesse `http://localhost:3000` no seu navegador

## Deploy na Vercel

Este projeto está configurado para ser facilmente implantado na Vercel. Basta conectar seu repositório e a Vercel cuidará do resto.
